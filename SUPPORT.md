# Support

## How to file issues and get help

This project uses GitHub Issues to track bugs and feature requests. Please search the existing issues before filing new ones to avoid duplicates. For new issues, file your bug or feature request as a new Issue.

For help or questions about using this project, please open a [GitHub Discussion](../../discussions) (preferred) or a GitHub Issue tagged `question`.

## Support scope

This repository is a **sample / reference implementation**. It is **not covered by Microsoft Support**. The content is provided as-is to help customers and Microsoft field teams plan and execute Azure AI Foundry model migrations.

For production support of the underlying Azure services (Azure OpenAI, Azure AI Foundry, etc.), follow the standard Azure support channels documented at [Azure Support Plans](https://azure.microsoft.com/support/plans/).

## Microsoft Support Policy

Support for this project is limited to the resources listed above.
